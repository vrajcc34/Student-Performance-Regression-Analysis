# Student-Performance-Regression-Analysis

## Overview
This project analyzes how different academic and lifestyle factors impact student performance using regression modeling. The goal was to identify key drivers of performance and build a model capable of generating accurate predictions.

## Dataset
The dataset includes 10,000 student records with:
- HoursStudied
- PreviousScores
- SleepHours
- SampleQuestionPapersPracticed
- ExtracurricularActivities
- PerformanceIndex (target variable)

## Methods
- Exploratory Data Analysis (histograms, scatterplots, boxplots)
- Multiple Linear Regression
- Stepwise Regression for model validation
- Diagnostic analysis (residual plots, normality checks)

## Key Results
- PreviousScores was the strongest predictor of performance
- HoursStudied also had a significant positive impact
- Sleep and practice contributed smaller but meaningful effects
- All variables remained significant in both full and stepwise models
- Model achieved R² ≈ 0.99, explaining nearly all variation in performance

## Tools
- SAS (regression modeling and diagnostics)
- Excel (data handling and visualization)
